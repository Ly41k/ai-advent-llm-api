# V15 — краткий ответ и полная поддержка выбранными цитатами

**Исторический V15 получен:** автоматическая оценка прошла, но ручной просмотр обнаружил неполноту объяснения семантической проверки до генерации. Следующая проба: [V16 — две обязательные части с отдельными цитатами](V16_PHASE_EVIDENCE.ru.md). Инструкция и ожидания V15 ниже сохранены как история.

## Что показал V14

Run d533b831-c284-4677-b285-396751e5f976: один вопрос base-03, один OpenAI вызов. Strict verifier и внутренняя согласованность прошли, исходное эвристическое качество 1/1. Generation wall 3.384 с, pipeline 4.536 с; стабильность по одному ответу не измеряется.

Ответ правильно различает Preflight до генерации и Postflight после неё/до сохранения. Описаны InvariantValidator, SemanticInvariantGuard, локальные/семантические проверки и отказы. Выбранные цитаты Three enforcement layers, Preflight и Postflight подтверждают эти факты. Основной дефект неполноты устранён.

Ручной просмотр обнаружил дополнительный недостаток: последнее предложение утверждает, что политика injected as a separate system block outside dialogue and memory. Полный retrieved context содержит отдельные разделы с такими сведениями, но модель не включила их в выбранные цитаты. Selected Result поддерживает отдельную non-overridable policy, но не всю детализацию её размещения. Это недостаток покрытия выбранными доказательствами, а не доказанная ложность факта. Автоматическое 1/1 остаётся сохранённым; оно не равно ручному подтверждению поддержки каждого предложения.

Исходный JSON не редактируется. Не добавляем цитаты задним числом и не пересчитываем прежнюю рубрику ради результата.

## Минимальная доработка

В `--quality-mode complete` V15 добавлены инструкции отвечать только на заданный вопрос, остановиться после его раскрытия и подтверждать выбранными IDs каждое фактическое предложение, включая последнее. Ненужные сведения об архитектуре/размещении/конфигурации удаляются из ответа самой моделью, если для них не выбраны доказательства. Для вопроса об этапах ориентир 3–5 предложений.

Один вызов, тот же полный retrieved catalog и прежняя схема answer + quote_ids. Нет скрытого второго вызова, автоматического ремонта, постобработки модельного текста или эталонного ответа в prompt. Модель, retrieval, индекс и исходная рубрика не меняются. Baseline V12 и coverage V13 сохранены; старый prompt V14 также сохранён отдельно для проверки исторического отчёта. Новый отчёт schema_version=15, prompt_revision=focused_complete_answer_v15; trace хранит answer_prompt_revision=v15.

## Следующая проба: только один вопрос, один вызов

Успешные VPS из V13 и изоляция из V12 не вызываются. Используется `questions-invariants-only.json`: точная копия исходного base-03 с неизменённой формулировкой и рубрикой. Это новый одновопросный subset, а не retry: retry от V14 ничего не вызвал бы, поскольку эвристическая оценка V14 прошла. Ручной недостаток цитирования является причиной новой пробы, а не изменением исходного отчёта.

```bash
python day-28-local-rag/main.py compare \
  --cloud-provider openai --only-provider cloud \
  --quality-mode complete \
  --questions day-28-local-rag/questions-invariants-only.json \
  --repeats 1 --max-tokens 1000 --cloud-rate-retries 0 \
  --output day-28-local-rag/reports/check/openai-quality-probe-v15.json

python day-28-local-rag/verify_report.py \
  day-28-local-rag/reports/check/openai-quality-probe-v15.json
```

После запуска проверить обе фазы, правильную последовательность и поддержку всех частей ответа выбранными цитатами. Если добавлен необязательный фон, он также должен иметь подходящие цитаты. Автоматический pass не заменяет этот просмотр.

Три повтора/полный набор сейчас не запускаются. При успешном ручном просмотре можно отдельно выбрать объём финальной проверки стабильности и регрессий; результаты разных версий остаются отдельными.
