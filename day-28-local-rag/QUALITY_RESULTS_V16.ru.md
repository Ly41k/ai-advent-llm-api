## Короткая финальная проверка стабильности исправления

Код менять не требуется. Если нужен контроль новой фазы после успешной одиночной пробы, повторяем только base-03 три раза с теми же настройками. VPS и изоляция не вызываются. Это три облачных генерации, без --synthesis и без --retry-from: retry от успешного отчёта ничего не вызовет.

```bash

  --cloud-provider openai --only-provider cloud \
  --quality-mode phases \
  --questions day-28-local-rag/questions-invariants-only.json \
  --repeats 3 --max-tokens 1000 --cloud-rate-retries 0 \
  --output day-28-local-rag/reports/check/openai-quality-stability-v16.json

  day-28-local-rag/reports/check/openai-quality-stability-v16.json
```

Отсутствие точного совпадения не означает ошибку, если механизм сохраняется. Режим phases специализирован для проверок до/после: полный набор других типов вопросов нельзя запускать в нём как универсальный quality benchmark.
