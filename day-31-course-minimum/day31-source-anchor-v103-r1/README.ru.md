## Что изменилось в v103

Общее правило Markdown: вводный prose block, заканчивающийся двоеточием,
связывается со следующим списком, таблицей или fenced block в том же разделе.
Между ними допускаются только пробельные символы. Вводная строка отдельно и
список без её квалификатора больше не предлагаются как варианты цитаты.
Поддерживается список сразу после вводной строки, без пустой строки.

Если составной фрагмент превышает прежние 600 символов, он не предлагается;
возврата к обрывку вводной или зависимому списку нет. Независимые предыдущие
предложения остаются доступны отдельно. Цитата всегда представляет точный
непрерывный span исходного файла, целиком входящий в уже предоставленный excerpt.
Текст за пределами excerpt в модель не добавляется.

В алгоритме нет названий вопросов, статусов и ожидаемых ответов. Промпты,
вопросы, критерии, evidence, retrieval, модель и параметры прежние. Все guards
проверки цитаты и text неизменны, что отдельно проверяется сравнением кода.
Меняется набор допустимых source_quote; версия schema:
status-source-quote-text-v2-linked-blocks. Prompt versions остаются прежними,
поскольку сами промпты не изменились. Ответ по-прежнему содержит точный text
модели без программного исправления фактов.

Точная цитата не доказывает семантическую правильность пересказа. Это изменение
проверяет конкретный дефект выделения опорных фрагментов, не закрывает всю
приёмку качества и не означает, что проблема fallback уже решена.

## Запуск на MacBook M1 32 GB

Из корня ai-advent-llm-api, в существующем Python 3.13+ окружении:

```bash
unzip -n ~/Downloads/day31-source-anchor-v103-r1.zip -d /tmp
python /tmp/day31-source-anchor-v103-r1/run.py run --root "$PWD"
```

Максимум **4 последовательные генерации**, RU-1 Single/Multi и EN-3 Multi/Single;
0 embeddings. Остальные четыре вопроса не отправляются модели. Это отдельный
эксперимент после изменения schema choices, не повтор старого прогона ради PASS.

Нужны прежнее приложение 0.7.29, native276, подтверждённая Ollama session,
preparation-bundle, production44 и research54, а также точный исходный v102:

```text
/tmp/day31-source-anchor-v102-r1-work/exports/bundle-0001.json
```

Не удаляйте предыдущие рабочие каталоги. Проверяются 60 application source SHA,
requirements, Git HEAD/branch, оба индекса, preparation, prior bundle, package,
контексты, модель и schema. Несовпадение останавливает запуск до генерации.
Перед dispatch на Mac выполняются **79 offline tests**. Native276 не повторяется.

Модель Qwen2.5:14b Q4_K_M, digest, temperature=0, seed=31, num_ctx=8192 и
num_predict=1024 прежние. Shared lease и uncertain checkpoint сохранены;
автоматических повторов генерации, рестартов, обновлений и cloud fallback нет.
Final calls используют keep_alive=0s. Day30 и другие Ollama-клиенты должны
оставаться выключенными; параллельный эксперимент запускать нельзя.

Ожидаемый первый результат:

```text
/private/tmp/day31-source-anchor-v103-r1-work/exports/bundle-0001.json
```

Пришлите один bundle по пути, который выведет скрипт. В нём ответы, evidence,
raw JSON, exact-anchor spans/digests/строки, validator replay и pending review.
Формат остаётся day31-evidence-bundle-v1.

## Сохранение и продолжение

Новый приватный каталог /tmp/day31-source-anchor-v103-r1-work. Append-only
hash-chain журнал, fsync, exclusive writes и process lock сохраняются.
Generation reservation пишется до dispatch; raw response — до validation;
каждый terminal result — сразу после выполнения. Экспорты получают новые
номера, прежние результаты не перезаписываются.

Первый Ctrl+C завершает и сохраняет текущий запрос, затем делает паузу.
Та же команда продолжает только отсутствующие режимы/вопросы без повторной
генерации сохранённых результатов. Второй Ctrl+C прерывает принудительно;
unresolved/uncertain запрос блокирует продолжение до разбора. Сохранённый
технический отказ не ремонтируется повторным запуском.

Экспорт сохранённых данных без вызовов моделей:

```bash
python /tmp/day31-source-anchor-v103-r1/run.py export --root "$PWD"
```
