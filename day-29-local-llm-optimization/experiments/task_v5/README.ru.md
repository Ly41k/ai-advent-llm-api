три новых ответа про VPS. Во всех новых ответах появились systemctl и journalctl,

Автоматические 12/15 теперь связаны с `expected_source_cited=false`: выбрана

привязки c3/c4 и язык ответа обнаружены независимо при чтении текста.
Рубрику и исходные результаты не изменяем ради PASS.

## Изменение

Для русского вопроса о проверке теперь используется русский шаблон с русским
примером. Он отдельно показывает, почему краткому чек-листу нельзя приписывать
команды и названия из других цитат. Пример содержит вымышленные команды
архивирования; правильного ответа Day 18, ожидаемых терминов или реальных IDs
в нём нет. Шаблон требует необходимую процедуру и допускает два или три пункта
вместо заполнения всех четырёх слотов.

Фактические вопросы сохраняют сообщения V3 побайтно. Английские процедурные
вопросы сохраняют шаблон V4. Выбор по тексту вопроса выполняется локально;
никакие expected_terms, expected_sources и ID кейсов в него не передаются.
Для выбора русского шаблона используется наличие кириллицы, что не является
полноценным определителем языка для смешанных вопросов.

Измеритель V1, модель, temperature=0, max_tokens=1024, num_ctx=8192, retrieval,
цитаты, схема JSON и seeds не меняются. Имя профиля focused-v3-q4 сохраняется
для reuse; фактический prompt и его hash записываются в каждой строке отчёта.
Новая русская процедура получает собственный ключ, старые ответы не редактируются.

## Запуск

Нужны установленные V3 и V4. Распакуйте архив в корень репозитория; добавляется
только `experiments/task_v5/`. Затем:

```bash
python day-29-local-llm-optimization/experiments/task_v5/main.py run \
  --profiles baseline focused-v3-q4 \
  --split all \
  --case base-07 base-06 base-08 base-10 negative-03 \
  --repeats 3 \
  --retry-from day-29-local-llm-optimization/reports/check/control-v4.json \
  --output day-29-local-llm-optimization/reports/check/control-v5.json
```

При прежнем окружении 27 результатов переиспользуются и генерируются только
три новых ответа оптимизированного профиля на base-10. Повтор после трёх ответов
не вызывает новых answer calls. Проверки prompt и прогрев отдельно учитываются.
Не меняйте модели, индекс, исходные файлы V1, series и параметры между запусками.

```bash
python day-29-local-llm-optimization/experiments/task_v5/main.py verify \
  day-29-local-llm-optimization/reports/check/control-v5.json
```

Критерии ручной проверки: русский ответ, конкретная проверка состояния службы,
проверка журналов и повторной работы/свежих результатов, прямая поддержка каждого
факта собственной цитатой. Дополнительные подробности включаются только если
подтверждены. Выбор английского эквивалентного источника может снова не пройти
строгую source-рубрику; это нельзя путать с семантической правильностью.
Качество V5 на реальной Qwen ещё не измерено.

## Проверки

Offline проверены импорт старых результатов, неизменность остальных prompt,
три новые генерации и отсутствие новых вызовов при повторе. Также на ключах

base-10. Эти проверки не оценивают реальные ответы модели.
