# Короткая демонстрация результата

Показываем сохранённые измерения; эти действия не запускают новую генерацию.

1. Открой SELECTED_PROFILE.json: Q4_K_M, temperature=0, max_tokens=1024,
   num_ctx=8192, справочная задача и factual V3 prompt.
2. Покажи FINAL_REPORT.ru.md: пример worker до/после, скорость по вопросам,
   аллокацию модели и сравнение Q4/Q5. Поясни, что времена сохранены, а
   size_vram не является полной физической памятью Mac.
3. В терминале выполни offline summary:

```bash
python day-29-local-llm-optimization/experiments/focused_v3/main.py summary \
  day-29-local-llm-optimization/reports/check/worker-quantization-v3.json
```

4. Открой review/manual-review.json: 12/12 в выбранной справочной области,
   оставшийся процедурный дефект и отсутствие редактирования сырых ответов.
5. Покажи README.ru.md с командой reuse четырёх справочных случаев. Не нужно
   повторно вызывать модель для записи демонстрации; при прежнем окружении
   эта команда использует сохранённые 24 наблюдения.

Корректная формулировка результата: «Выбран Q4/V3 для коротких справочных
ответов по репозиторию. Качество и ресурсы проверены на небольшой выборке;
для процедур обнаружено ограничение, которое задокументировано».
