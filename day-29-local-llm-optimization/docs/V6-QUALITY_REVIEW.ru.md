# Приёмка качества: обязательные критерии

Число совпавших ключевых слов не заменяет эти проверки. Оценивать нужно каждый
из трёх исходных ответов, без выбора лучшего или переписывания неудачного.

| Критерий | Что проверяем |
|---|---|
| Язык и цель | Ответ на языке вопроса; процедура проверки вместо установки |
| Прямая поддержка | Каждое существенное утверждение подтверждает именно его quote_id |
| Техническая точность | Точные команды, имена, аргументы и файлы есть в выбранной цитате |
| Состояние / выполнение | Работающий процесс не объявлен доказательством выполнения задачи |
| Периодичность | Несколько последовательных результатов/время сопоставляются с расписанием; один снимок недостаточен |
| Сохранение результатов | Пояснено, где и каким документированным способом проверить результаты |
| Неполные источники | Только поддержанная часть ответа или отказ; частичность не выдана за полноту |
| Фактическое состояние | План проверки не выдан за уже проверенный VPS или гарантию работы |
| Лишние сведения | Нет нерелевантной установки, ключей, reboot или постороннего механизма |
| Стабильность | Все три ответа оцениваются отдельно; одинаковый ответ может быть одинаково неверным |

Для процедурного VPS-вопроса нужны документированные команды наблюдения,
результат выполнения и проверка повторения/сохранённых снимков. Конкретный
VPS ассистент не проверял: нельзя объявлять работающим само развёртывание.

Автоматические проверки маркируют ready_for_manual_review или blocked.
Полный ручной PASS ставится только при корректном и достаточном ответе.
Частичный полезный ответ сохраняется с PARTIAL; он не закрывает полную процедуру.
Сырой ответ, оценка автора эксперимента и независимое ревью хранятся раздельно.

base-10 использовался для настройки V4/V5/V6 и больше не считается нетронутым
holdout. После фиксации шаблона проверяются новые вопросы, включая другой
механизм/язык. Неудачу на новом вопросе сохраняем, а не исключаем из оценки.

Окончательное подтверждение расширения области — после живого V6-контроля
и отдельного transfer-контроля. Пока этот этап не завершён, указываем pending.
