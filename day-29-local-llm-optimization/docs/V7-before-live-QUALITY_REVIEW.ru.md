# Приёмка V7

Проверяются все три исходных выбора модели и три собранных ответа, а не лучший.

1. Выбраны все четыре нужных этапа, ID реально пришли от локальной модели.
2. Каждый ID соответствует роли, точному source/excerpt/parent и исходному тексту.
3. В показанной процедуре только команды наблюдения; нет установки, enable/restart.
4. Состояние процесса отделено от выполнения самой задачи.
5. Указано наблюдение повторных результатов и сопоставление с расписанием,
   доступны документированные способы проверки сохранённых данных.
6. План не выдан за уже проверенный конкретный VPS; нет обещаний 24/7/100%.
7. Язык плана соответствует вопросу; цитаты сохраняют исходный язык.
8. Raw model selections и application rendering явно разделены в отчёте.
9. Все факты и операции релевантны вопросу. Role detectors не заменяют смысловую оценку.
10. Повторный запуск не генерирует новый вариант законченного ответа.

Ready_for_manual_review не равен ручному PASS. Неполный выбор сохраняется с
отказом и диагнозом; он не закрывает задачу. Полезные, но недостаточные сведения
не объявляются полной процедурой. В V7 выбран fail-closed режим полного ответа.

base-10 использовался для настройки и не является независимым holdout.
После фиксации проводятся две новые проверки той же задачи. Другие процедуры,
общий диалог или свободные рассуждения не входят в подтверждённую область.
