# Открытые этапы V7

1. Живой контроль: 27 reused и 3 новых выбора доказательств при прежней среде.
2. Ручная оценка selections и собранной процедуры отдельно.
3. Заморозить V7 и проверить две новые формулировки, по три ответа на вопрос.
4. Только после проверки обновить подтверждённую область и финальные выводы.

V7 не улучшает универсально свободную речь/рассуждение модели. Контракт
предназначен для источниковой проверки периодического фонового сервиса.
Консервативные role detectors могут отказаться при достаточной информации
или требовать ручного разбора релевантности. Полный смысл не доказывается
регулярными выражениями. Другие процедуры остаются отдельной задачей.

Слабые варианты сохраняются. При изменении будущего контракта сохраняется
V7 decoder для чтения истории. Генерацию не повторяем ради PASS.
