# Открытые этапы после подготовки V6

1. Живой контроль V6 на Mac: только три новых ответа про VPS, остальные 27 reuse.
2. Ручное ревью всех трёх ответов по QUALITY_REVIEW.ru.md.
3. После фиксации шаблона — две новые transfer-проверки, по три ответа на вопрос.
4. После оценки — обновить выбранную область применения и финальный отчёт,
   сохранив прежние результаты, ограничения и неудачные варианты.

Реализованы техническая проверка привязок и отдельная оценка полноты, но они
не являются универсальным доказательством смысла. Если останутся ошибки,
дальнейшее изменение должно следовать из конкретного дефекта, не из желания
получить PASS перебором. Дополнительный локальный аудитор рассматривается
только при необходимости; облачная генерация не требуется.

Качество процедур пока pending. Справочные V3-результаты сохраняют прежнюю
подтверждённую область. Изолированный эффект температуры и полный физический
расход unified memory не измерены; эти границы нельзя убрать из отчёта словами.
