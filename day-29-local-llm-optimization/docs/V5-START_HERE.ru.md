# Начать с итогового результата

Распакуй каталог в существующий репозиторий. Кэш не удаляй.
Открой FINAL_REPORT.ru.md: качество, скорость, ресурсы и известное ограничение.
Выбранная область — короткие справочные ответы. Процедурный VPS-вопрос пока
не прошёл ручную проверку. Сохранённые ответы не нужно получать повторно.

Offline-проверка отчёта:

```bash
python day-29-local-llm-optimization/experiments/focused_v3/main.py verify \
  day-29-local-llm-optimization/reports/check/control-v5.json
```

Для формирования справочного сравнения из сохранённых результатов используй
команду в README.ru.md. При прежнем окружении она не делает новых генераций.
Все восемь исходных отчётов и отдельная ручная оценка уже находятся в архиве.
