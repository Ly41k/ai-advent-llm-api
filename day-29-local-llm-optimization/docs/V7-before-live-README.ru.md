# День 29 — локальная оптимизация и ограниченный процедурный контракт V7

Все embeddings, retrieval и модельные вызовы локальны. Qwen2.5 14B Instruct
Q4_K_M: temperature=0, max_tokens=1024, num_ctx=8192. Прежние сравнения Q4/Q5,
качества, скорости и ресурсов сохранены. Справочный V3 прошёл ручную проверку
12 ответов из четырёх вопросов и остаётся неизменным.

Процедурный V6 не прошёл ручную проверку, несмотря на улучшившиеся привязки.
В новой V7 периодическая процедура использует явный контракт:

Question → local retrieval → exact evidence units → local Qwen selections →
role/source validation → application-rendered procedure → independent review

Модель выбирает ID для состояния, журнала, результата выполнения и повторных
сохранённых результатов/расписания. Приложение не создаёт недостающие выборы
и не подменяет их. Неполный или неправильный выбор даёт отказ и отдельный
диагноз, сохраняя сырой вывод и кеш. Дополнительной LLM для сборки/аудита нет.

**V7 ожидает живую проверку.** Её нельзя объявлять исправленной только по
offline-тестам. Начни с START_HERE.ru.md: 27 прежних наблюдений и максимум
3 новых при прежнем окружении. Инструкция: QUALITY_V7.ru.md.

Распакуй поверх существующего Day 29 и сохрани кеш. Все V1–V6 Python-файлы
побайтно сохранены. Новые decoder/transport/renderer/audit находятся в
experiments/quality_v7. Имя настроек focused-v3-q4 сохраняет справочный кеш;
messages, catalog, contract и policy hash идентифицируют новый опыт.

Сырые procedural generation.answer содержат **выборы доказательств**, а не
свободный текст ответа. response.answer собирает приложение. Сравнение
латентности/числа output_tokens обязано учитывать эту смену контракта:
токены выбора не равны длине показанной процедуры и не доказывают улучшение
свободной генерации Qwen. Decoder проверяется тем же launcher V7 при resume,
verify и audit. Старые launcher не поддерживают новый контракт.

Девять исходных живых JSON-отчётов не изменены. Оригинальный V6 guard-отчёт
сохранён в review/control-v6.quality.original.json; пересмотр оценки отдельно
в review/quality-v6-reanalysis-v7.json, ручной разбор в review/control-v6-manual.json.
Ручные правила: QUALITY_REVIEW.ru.md. История измерений: FINAL_REPORT.ru.md.
