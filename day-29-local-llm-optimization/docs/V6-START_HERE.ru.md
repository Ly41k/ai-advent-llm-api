# День 29 — продолжаем проверку качества, V6

Распакуй каталог в корень существующего репозитория. Кеш не удаляй.
Новые модели, зависимости и перестройка индекса для V6 не требуются.
Исходный измеритель и V1–V5 сохранены без изменения Python-файлов.

V6 подготовлен, но ещё не проверен живой Qwen на твоём Mac. Качество
процедурного ответа пока не объявлено исправленным. Справочные результаты V3
остаются действительными; прежние отчёты не переписаны.

Запусти из корня репозитория с работающей Ollama:

```bash
python day-29-local-llm-optimization/experiments/quality_v6/main.py run \
  --profiles baseline focused-v3-q4 \
  --split all --case base-06 base-07 base-08 base-10 negative-03 --repeats 3 \
  --retry-from day-29-local-llm-optimization/reports/check/control-v5.json \
  --max-new-observations 3 \
  --output day-29-local-llm-optimization/reports/check/control-v6.json
```

При прежнем окружении: **27 reused / 3 new**. Это три ответа только на
процедурный вопрос. Контекстный probe и прогревы — отдельные служебные вызовы
(обычно один probe и три прогрева); они отражаются в JSON. Повтор той же
команды переиспользует три законченных ответа даже при плохом качестве:
новых ответов, probes и прогревов не будет.

Если ключи окружения поменялись, лимит всё равно ограничит пакет тремя новыми
наблюдениями. В таком случае отчёт может быть paused: это не завершённый контроль.

После запуска нужны два файла:

- `reports/check/control-v6.json` — исходные ответы и измерения;
- `reports/check/control-v6.quality.json` — отдельная проверка доказательств.

Exit code 1 может означать обнаруженный дефект качества, а не потерю ответов.
Не меняй series/seed и не удаляй кеш, чтобы добиваться PASS повторениями.
