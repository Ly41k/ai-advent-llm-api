# V7 — ограниченный выбор доказательств для периодической процедуры

V6 прошёл техническую проверку отчёта, но **не прошёл ручную проверку ответа**:
три одинаковых ответа на английском, команды установки и отсутствие
действий проверки повторных сохранённых результатов. Исходные файлы сохранены.

V7 подготовлен, но пока не проверен живой Qwen на Mac. В процедурном режиме
модель выбирает четыре ID доказательств. Приложение проверяет роли и собирает
ответ из точных цитат и явного плана наблюдения. Это другой контракт, а не
исправление старого сырого ответа или дообучение модели.

Распакуй каталог в корень существующего репозитория. Кеш не удаляй.
Новые модели, зависимости и перестройка индекса не требуются.

```bash
python day-29-local-llm-optimization/experiments/quality_v7/main.py run \
  --profiles baseline focused-v3-q4 \
  --split all --case base-06 base-07 base-08 base-10 negative-03 --repeats 3 \
  --retry-from day-29-local-llm-optimization/reports/check/control-v6.json \
  --max-new-observations 3 \
  --output day-29-local-llm-optimization/reports/check/control-v7.json
```

При прежнем окружении: **27 reused / 3 new**. Новые только три процедурных
выбора модели. Probe и прогревы учитываются отдельно (обычно один и три).
Повтор того же опыта переиспользует законченные ответы, даже плохие или
неполные выборы; не будет новых ответов, probes и прогревов.

Лимит 3 новых наблюдений действует и при изменённой среде: такой отчёт может
быть paused, что не означает завершение контроля. Не меняй seed/series и не
удаляй кеш ради получения PASS.

Для разбора нужны `control-v7.json` и `control-v7.quality.json`.
В первом `generation.answer` — сырой выбор модели; `response.answer` —
детерминированная сборка приложением. Во втором — проверки и диагноз.
При exit code 1 законченные результаты всё равно сохранены.

**Отчёты V7 проверяй launcher V7**, который знает новый контракт и читает V1–V6:

```bash
python day-29-local-llm-optimization/experiments/quality_v7/main.py verify \
  day-29-local-llm-optimization/reports/check/control-v7.json
```

Старый V1/V6 launcher не знает selector-contract V7. Прежние файлы измерителя
сохранены; декодер нового контракта изолирован в experiments/quality_v7.
