# v24 — установка и короткая проверка

Архив обновления совместим с опубликованной v22 (`8f2b24f`) и установленной поверх неё v23. Распакуйте из корня репозитория с заменой включённых файлов. В архиве только файлы дня 25: рабочие `chats.db`, индекс, `.env`, окружение и дни 21–24 не включены. Миграция существующих таблиц не требуется.

Важные изменения: сохранение темы после сбоев; защита live-turn от recover; единый снимок экспорта; строгий модельный JSON; проверка реальных RAG-вызовов; новые процессы в длинном тесте; checkpoint/resume; усиленная проверка источников и памяти. [Полный аудит](AUDIT_V24.ru.md).

## Сначала без расходов Ollama

В обычном терминале из корня репозитория:

```bash
source .venv/bin/activate
python day-25-rag-chat/test_day25.py StoreTests JsonOutputTests MemoryTests SourceUnitTests -v
python day-25-rag-chat/test_day25.py -v
python day-21-document-indexing/main.py verify
```

Полный набор: 181 тест; модели и внешние API заменяются локальными fixtures. Эти проверки не запускают часовой live-тест. На macOS/Linux используются POSIX-блокировки стандартной библиотеки; дополнительных pip-пакетов нет. Новые отчёты проверки раньше не создавались вашим старым архивом: они входят в v24.

Если verify сообщает stale/corpus mismatch, выполните `python day-21-document-indexing/main.py build`, затем verify. Само применение v24 не меняет индексируемый корпус; уже свежий пользовательский индекс не надо перестраивать. Новый Git-коммит изменяет revision и может потребовать build/verify перед следующей живой проверкой.
