## Два исправления v22

- Ошибочный отказ о --task summary. Сам ответ q1_12 верно называет GitHub и analysis без сохранения файла, но auditor требовал повторить «день 20» внутри цитаты вместо чтения lesson_scope. Для одного явно указанного --task NAME добавлен краткий route audit на русском: тот же полный question, критерий, все исходные proof_units/provenance и schema. Источник подтверждает принадлежность к дню, а поведение по-прежнему должно подтверждаться текстом. Точные функции и порядок обязательны при явном запросе. Один verdict; отрицательный ответ не исправляется в положительный и не повторяется до одобрения. Не добавлены expected answer, скрытая таблица правильных маршрутов или model-free approval.
- Обрезанная цитата Python `Args: ... """ ... return scheduler.summary(...)`. В старом tokenization IndentationError возникал раньше незакрытого docstring delimiter. Теперь при ошибке отступов выполняется второй **лексический** просмотр без ведущих отступов строк. Это не исполнение Python и не изменение публикации: весь плохой quote ID удаляется; исходный текст никогда не восстанавливается и не обрезается. Валидные строки, комментарии и фрагменты тела функции сохраняются. Настоящий quote v21 проверен новым тестом.
