Живой `long-init-v10.json` не прошёл: память и поиск исправлены, но coverage auditor ошибочно заявил, что таблица не содержит имён серверов. Исходный отчёт сохранён без изменений в `reports/live/long-init-v10-original.json`; разбор — в `long-init-v10-review.json`.

Цель и ограничение сохранены полностью, с точками; предупреждений нет. Две свежие dense-ветки нашли только источники дня 20. Первый README имеет cosine 0.6514977232210695. Selector выбрал таблицу с `github`, `analysis`, `storage`, а также вступление и ненужный абзац о тестах. Auditor отверг таблицу, после чего selector отказался отвечать. Этот результат не считается успешным.

## Изменение

- Selector получает ограниченный индекс дословных табличных ячеек с исходными quote IDs: заголовок столбца помогает отличить имя сервера от инструмента и роли. Чужие/запрещённые quote IDs не индексируются.
- Если в выбранном ответе есть корректная Markdown-таблица, auditor получает компактную инструкцию на русском вместо длинной общей инструкции. Исходные question_context, coverage_requirement, lesson_scope и ВСЕ proof_units остаются неизменными. Имена следует читать из соответствующего столбца; отдельный повтор в прозе или код регистрации нужны только при явном запросе такой детали.
- Это один вызов auditor, без повторения отрицательного семантического вердикта ради одобрения. Приложение не назначает covered=true. Отрицательный ответ и неизвестные/выдуманные IDs проходят прежние строгие проверки Day 24. Для запросов путей, ролей, порядка и условий по-прежнему нужны прямые доказательства всех запрошенных частей; порядок строк таблицы не считается порядком вызовов.
- Поиск, порог, источники, история, память и Python дней 21–24 не изменены.

Распакуйте архив в корень `ai-advent-llm-api`, заменив `day-25-rag-chat/`. Он включает предыдущие исправления и не содержит баз данных, окружения или ключей. Пересборка индекса не требуется.

Повторите вопрос в той же сессии:

```bash
python day-25-rag-chat/main.py ask \
"Какие MCP-серверы зарегистрированы на день 20?" \
--session 4fb98ce5a966406688e4d80b51cfa7ba \
--output day-25-rag-chat/reports/check/long-init-v11.json
```

Нужны ответ с тремя именами, подтверждённый источник дня 20 и положительная реальная проверка полноты. Цель и «Без VPS.» должны сохраниться. До проверки этого файла живой PASS не заявляется.
