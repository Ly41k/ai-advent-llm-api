## Изменения

1. Приложение разбирает самостоятельные строки `Цель:`, `Ограничение:`, `Уточнение:`, `Термин:` (и английские аналоги), сохраняет полное дословное значение с текущим evidence через прежние проверки памяти. Модельные перефразирования этих же полей игнорируются; это не принятие выдуманного evidence. Цитаты/Markdown-фенсы не рассматриваются как явные объявления.
2. Для определения текущего вопроса метки памяти отделены от текста запроса. Привязка к дню сохраняется и при перефразировании короткого вопроса. Явный день текущего вопроса/уточнения имеет приоритет над прошлой темой. При модельной неоднозначности в известном контексте выполняется одна повторная проверка reference; повторный отказ остаётся отказом, неизвестный объект не назначается автоматически.
3. Поиск явно одного дня сначала ограничивает namespace по индексированным source paths, затем применяет candidate/final limits. Две свежие query embeddings: обычный запрос и тот же запрос с заголовками индексированных документов. Слияние по максимальному реальному cosine, затем неизменный порог 0.50. Числа не подменяются; обе ветки, их запросы и оценки записаны в `retrieval.lesson_retrieval`. Ни ответы истории, ни память не добавляют source evidence. Для неопределённого/множественного дня или отсутствующего namespace остаётся прежний глобальный поиск.
4. Selector получает память и прошлые пользовательские темы, но не старые ответы ассистента. Audit по-прежнему получает только новый question/proof context. Уточнён scope: завершение задачи должно подтверждаться её условием приёмки, а не одним сохранением файла. Отрицательные verdict не превращаются в положительные.
5. Уточняющая фраза отказа больше не требует назвать день, уже указанный в вопросе. CLI техническая ошибка также выводит блок источников. История ошибки сохраняется как `error`, не как подтверждённый ответ.

## Установка и следующий шаг

Распакуйте архив в корень существующего `ai-advent-llm-api` с заменой файлов `day-25-rag-chat/`. Он включает предыдущие исправления. `chats.db` и `knowledge.db` не входят в архив; удалять их или пересобирать индекс из-за этого исправления не требуется. Python дней 21–24 не изменён.

Сначала проверьте новую чистую сессию:

```bash
python day-25-rag-chat/main.py ask \
"Цель: Подготовить демонстрацию полного MCP-флоу дня 20.
Ограничение: Без VPS.
Какие MCP-серверы зарегистрированы на день 20?" \
--output day-25-rag-chat/reports/check/long-init-v10.json
```

Ожидаем точные цель/ограничение с точками, ответы с источниками дня 20 и trace двух веток поиска. Затем проверяются проблемные вопросы по одному, после чего новый полный `evaluate` 12+12. До такого отчёта v10 live-pass не заявляется.
