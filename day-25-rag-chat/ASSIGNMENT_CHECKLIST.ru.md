# Сверка задания дня 25

| Требование | Реализация | Проверка и границы |
|---|---|---|
| Мини-чат CLI/веб | CLI `main.py chat` | Интерактивный subprocess с вопросами/командами/экспортом |
| Хранит историю диалога | `chat_turns`, полный вопрос и ответ/источники/trace или status error | SQLite, повторное открытие файла, восстановление complete/pending/error |
| На каждом новом вопросе ищет контекст через RAG | `ChatAgent.ask` → planner → Day23/StrictRAG retrieval | 48 свежих query embeddings на 24 scoped хода; даже неоднозначный вопрос запускает поиск |
| Отвечает по найденной информации | `StrictRAGAgent` v14, exact quote selection, coverage audit | Реальные Day24 validators; неизвестный quote ID и отрицательная полнота блокируют strict-ответ |
| Всегда выводит источники | `render_response`: Sources + provenance; при отказе явное отсутствие источников | Success, empty context, ambiguous reference, invalid evidence, diagnostic flag |
| Что пользователь уточнил | `task_state.clarifications` | Дословное происхождение от текущего пользователя, сохранение после перезапуска |
| Ограничения | `task_state.constraints` | Сохраняются отдельно от sliding history; передаются planner и evidence selector |
| Термины | `task_state.terms` | NAME=definition, исправление/удаление, provenance и изоляция между сессиями |
| Цель диалога | `task_state.goal` | Поздние вопросы получают цель вне окна истории; явная смена протестирована |
| 2 длинных сценария по 10–15 сообщений | Два сценария по 12 user turns = по 24 сообщения с ответами | 48 сообщений суммарно; after turn 6 закрытие и повторное открытие баз |
| Цель не теряется, ответы сохраняют источники | Per-turn goal/source contract, final all-memory checks | Все 24 scripted хода проходят; семантическое соблюдение цели реальной моделью требует live/source review |
| Готовое решение | Код, зависимости stdlib, сценарии, отчёты, RU/EN инструкции | Архив полного проекта с manifest; без ключей, рабочих SQLite и виртуального окружения |

Автоматические проверки подтверждают программную реализацию требований. Дословное происхождение памяти не гарантирует правильность её модельной интерпретации; сохранение цели не доказывает, что реальная модель соблюла её смысл во всех ответах. Живой прогон `main.py evaluate` и `manual_review` для всех 24 ходов предусмотрены, но не выполнены в среде подготовки без Ollama. Не выдавать scripted contract pass за доказательство качества настоящей модели.
