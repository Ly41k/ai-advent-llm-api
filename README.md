# AI Advent — практика работы с LLM API

Учебный репозиторий с практическими заданиями курса AI Advent.

Проект последовательно знакомит с работой через LLM API: от первого запроса и сохранения истории диалога до управления форматом ответа и сравнения разных способов рассуждения.

## Выполненные задания

| День | Тема | Результат |
|---|---|---|
| [День 1](day-01-first-api-request) | Первый запрос к LLM через API | Консольный чат-бот с историей диалога |
| [День 2](day-02-response-control) | Управление форматом ответа | Сравнение ответа без ограничений и с заданным форматом |
| [День 3](day-03-reasoning-methods) | Разные способы рассуждения | Четыре решения одной задачи и их автоматическое сравнение |

## Технологии

- Python;
- [Groq API](https://console.groq.com/);
- модель `openai/gpt-oss-20b`;
- Groq Python SDK;
- `python-dotenv`.

## Подготовка проекта

### 1. Клонирование

```bash
git clone https://github.com/Ly41k/ai-advent-llm-api.git
cd ai-advent-llm-api
```

### 2. Виртуальное окружение

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

macOS/Linux:

```bash
source .venv/bin/activate
```

Windows:

```bash
.venv\Scripts\activate
```

### 3. Зависимости

```bash
pip install -r requirements.txt
```

### 4. API-ключ

Получите ключ в [Groq Console](https://console.groq.com/keys).

Создайте в корне проекта файл `.env` на основе `.env.example`:

```env
GROQ_API_KEY=your_api_key_here
```

Файл `.env` уже добавлен в `.gitignore`. Не публикуйте его и не передавайте другим людям.

## Запуск заданий

Все команды выполняются из корня репозитория.

День 1:

```bash
python day-01-first-api-request/main.py
```

День 2:

```bash
python day-02-response-control/main.py
```

День 3:

```bash
python day-03-reasoning-methods/main.py
```

Программы первого и второго дня работают в интерактивном режиме. Для завершения введите:

```text
выход
```

Третий день использует заранее заданную логическую задачу и самостоятельно завершает работу после получения и сравнения всех ответов.

## Что изучено

### День 1

- создание клиента Groq;
- роли `system`, `user` и `assistant`;
- отправка запроса и получение ответа;
- хранение истории текущего диалога;
- обработка ошибок API.

### День 2

- управление структурой ответа через промпт;
- смысловое ограничение длины;
- параметр `max_completion_tokens`;
- явное условие завершения ответа;
- сравнение результатов с одинаковым пользовательским запросом.

### День 3

- прямой запрос без дополнительных инструкций;
- пошаговое решение;
- генерация промпта самой моделью;
- имитация группы экспертов;
- автоматическая оценка нескольких решений;
- обработка ограничения токенов в минуту.

Код третьего дня содержит подробные комментарии на русском языке, объясняющие основные строки и этапы выполнения программы.

## Ограничения Groq API

Доступное количество запросов и токенов зависит от тарифного плана Groq. В третьем задании используется ограничение `max_completion_tokens=2048` и низкий уровень внутренних рассуждений.

Если несколько последовательных запросов временно исчерпают лимит токенов в минуту, программа подождёт 60 секунд и один раз повторит запрос.

## Цель репозитория

Главная цель проекта — на небольших запускаемых примерах понять, как формулировка промпта и параметры API влияют на поведение языковой модели.
