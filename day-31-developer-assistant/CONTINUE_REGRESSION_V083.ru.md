# Продолжение известной регрессии v083

Версия приложения остаётся 0.7.13: Python, промпты, схемы, индекс и настройки моделей не меняются.
Распакуйте архив из корня репозитория. Здесь только новый shell-скрипт и отчёты.

Запуск из корня репозитория, в активном Python-окружении:

```bash
bash day-31-developer-assistant/scripts/continue_regression_v083_mac.sh receipt
```

Каждый запуск выбирает ровно два известных вопроса (RU/EN), сравнивает Single/Multi
на общем snapshot и выполняет до 4 либо 6 последовательных модельных вызовов.
Скрипт не запускает следующий пакет сам. Сначала дождитесь завершения и проверки результатов.

| Пакет | Тема | Верхняя граница вызовов |
|---|---|---:|
| receipt | HTTP 202 и состояние генерации | 4 |
| assistant | Текст ассистента и проверенные факты | 4 |
| dense | Project RAG и личная память + ветка | 6 |
| language | Язык ответа и оригинальные цитаты | 4 |
| paths | Лимит путей и границы связи с документацией + ветка | 6 |
| main | Полномочия Main + ветка | 6 |
| paraphrase | Лексический поиск, перефразировки и embeddings | 4 |
| uncertain | Потерянный ответ, uncertain и cloud fallback + ветка | 6 |

Отчёты: `/tmp/day31-paired-<пакет>-mac-v083-{index-verify,plan,freeze,result}.json`.
Отправьте четыре файла после завершения. При остановке отправьте отчёты и текст ошибки;
не удаляйте результаты и не повторяйте прогон автоматически.

Скрипт использует уже прошедший `/tmp/day31-stage7-preflight-mac-v083.json`:
252 native tests и точное совпадение 59 Python-хэшей. Дополнительно проверяет digest
каталога и точный лимит выбранного плана. Полную suite, admission и index build не повторяет.
Каждый пакет создаёт свой новый paired freeze. Другие клиенты Ollama и Day30 должны быть выключены,
как в основной инструкции выделенной сессии.

Текущий итог трёх завершённых пакетов: 6 пар, 12 ответов, 14 известных вызовов,
13006 входных / 765 выходных токенов; технических ошибок нет.
Unknown 4/4 корректно отказывается. Untracked 4/4 сохраняет запрет; RU Multi дублирует факт.
Serialized: Single не называет отвергнутую альтернативу; Multi не прикладывает e2 к запрету копий.
Это известная регрессия, не независимая semantic acceptance и не held-out/E2E.
Входные native JSON сохранены без изменения; review выполнен Codex, human review остаётся pending.
